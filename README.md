# 1024 解愿扭蛋局

一台可以在网页里真实摇动的 3D 扭蛋机：摇一摇，随机掉出一颗扭蛋，蛋里是另一位同学的真实烦恼；拿到问题的人想办法解决它，能用技术就用技术。

**玩法闭环**：许愿（投出烦恼）→ 扭蛋（抽到心愿卡）→ 我来解愿（提交办法）→ 还愿（办法变金蛋回投 + 还愿墙）

- 纯静态站点，Three.js 已内置（`vendor/`），任意静态托管均可运行
- 数据：`data/problems.json`（52 条匿名学生问题，来自《采购管理》课程两个班）
- 解愿记录存于浏览器 localStorage（本机有效，不跨设备）
- 桌面端：点击按钮 / 空格键摇动；手机端：摇一摇（Android 直接可用，iOS 请点按钮）

## 本地预览

```bash
npx serve .        # 或任意静态服务器
```

## 课程活动背景

1024 程序员节 ×《采购管理》课程：同学的问题，扭个办法。
